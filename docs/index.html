Dethrace Slop Pack is a personal mod fork of Dethrace, the reverse-engineered Carmageddon 1 engine. Adds a pile of features, bug fixes, and the Meld system — merging C1, Splat Pack, and Xmas Demo into one unified campaign at runtime, no file copying needed.

Not intended for upstream contribution. This is AI-assisted and heavily personalised. Upstream devs are welcome to anything useful.

Screenshots

Features

Graphics

  • Custom resolution + widescreen support (3dfx mode)
  • Widescreen 2D cockpits (21:9, if present via Meld)
  • MSAA & Sample Rate Shading / supersampling
  • Vastly extended draw distance — geometry, opponents, peds, powerups
  • Opponent LOD always max, view distance 10×
  • Configurable skid/blood/oil decal limits — last the whole race
  • Decals no longer hover above ground

Gameplay

  • Achievements system
  • Dynamic Meld — C1 + Splat Pack + Xmas Demo in one campaign
  • Multiplayer arena tracks (SUMO, COLISEUM) added to campaign
  • Opponent player character added as a campaign racer
  • Configurable car stealing (any car, probability, rank gate off)

Quality of Life

  • Loads cutscenes direct from GAME.GOG / SPLAT.GOG — no manual extraction
  • Easier modding hooks

Bug Fixes

  • Camera judder on slopes — fixed since 1997!
  • Pedestrian spasm/flicker — fixed since 1997!
  • 3dfx fog tint, z-fighting at high draw distance, texture zoom
  • Submersion physics, opponent splash sounds, car shadow flicker
  • Sky black band via GL_DEPTH_CLAMP
  • ProcessGetNearPlayer + ReverseSound crash fixes

Install

Same as upstream Dethrace. Build from source or grab a release binary.

For arena race cards (MeldNetRaces), copy the bundled DATA/ folder next to the executable.

Configuration

All options live under [Slop] in dethrace.ini:

[Slop]
Meld                    = 1       ; merge all [Games] installs into one campaign
MeldBothStartingCars    = 1       ; start with both variants of your car
MeldNetRaces            = 1       ; add SUMO + COLISEUM to the campaign

Achievements            = 1

Width                   = 3840    ; custom resolution
Height                  = 2160
Msaa                    = 8       ; 0 / 2 / 4 / 8
SampleRateShading       = 1       ; MSAA → SSAA

CameraJudderFix         = 1
ExtendDrawDistance      = 1
FixPedSpasm             = 1

StealworthyAllCars      = 1
StealworthyPercentage   = 50
StealworthyRankLimitDisable = 1

NumSkids                = 65535   ; max decals (default 100)

Game directories for Meld go under [Games]:

[Games]
Game1 = /path/to/CARMAGEDDON
Game2 = /path/to/SPLAT_PACK
Game3 = /path/to/XMAS_DEMO

Build

Install dependencies:

# macOS
brew install SDL2 cmake

# Linux
apt-get install libsdl2-dev cmake

Clone and build:

git clone https://github.com/TRPB/dethrace
cd dethrace
git submodule update --init --recursive
mkdir build
cd build
cmake ..
make
